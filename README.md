# TrapBook

Free polyglot chess opening book loaded with traps (3.8 MB, 247,907 positions).

64 hand-built trap lines for both colors — Stafford, Fried Liver, Legal's Mate,
Traxler, Noah's Ark, Blackburne Shilling and more — on top of a full sound
repertoire, so the engine plays real chess until someone grabs the bait.

## Use

Point any polyglot-compatible engine or GUI at `booktrick.bin`:
Komodo, Rodent and other UCI engines with a Book File option, Stockfish via
the PolyGlot adapter, Arena, Banksia Gui, CuteChess, Scid vs. PC, Lucas Chess.
Android: DroidFish (copy to the `DroidFish/book` folder).
Not for ChessBase/Fritz (proprietary `.ctg` only).

## Who is this for

Engine vs human — not engine vs engine. Tested: −53 Elo (not significant)
vs Stockfish without book, 8–0 vs Maia 1600, 10–0 vs blunder-prone play.
Traps only fire when the opponent grabs the bait — engines don't, humans do.
